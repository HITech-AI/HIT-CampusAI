# HIT-CampusAI 技术方案文档（V1.0）

## 一、整体架构设计
采用“**知识库检索 + 大模型推理**”的技术方案，确保回答的准确性和专业性。整体架构分为四层：

1. **交互层**：Streamlit网页端，提供友好的文字交互界面。
2. **应用层**：核心功能逻辑（问答、推荐、提醒）。
3. **引擎层**：大模型接口、向量检索引擎（FAISS）。
4. **数据层**：哈工大校园知识库（结构化数据）。

## 二、核心技术选型
| 技术模块 | 选型方案 | 选型理由 |
| :--- | :--- | :--- |
| **基础模型** | 哈工大AI开发平台国产大模型 | 大赛官方支持，合规稳定，无需担心算力成本 |
| **检索引擎** | FAISS-CPU | 轻量级，适合本地部署，无需高端显卡 |
| **前端框架** | Streamlit | 开发效率极高，单人可快速搭建美观界面 |
| **后端框架** | FastAPI（可选） | 为后续接口扩展预留，中期版本引入 |
| **开发语言** | Python 3.10+ | 生态丰富，适配大模型与数据处理 |

## 三、核心功能实现思路
### 1. 校园智能问答
1. **数据采集**：爬取/整理哈工大官网办事指南、图书馆规则、校历等公开文本。
2. **向量入库**：使用模型将文本向量化，存入FAISS向量库。
3. **检索推理**：用户提问 → 向量化 → 检索相似文本 → 传入大模型生成回答。

### 2. 食堂美食推荐
1. **数据准备**：整理各校区食堂菜单（手动录入基础数据）。
2. **推荐算法**：基于用户口味标签（辣/甜/咸）和用餐时段，进行简单的规则推荐。

## 四、开发与部署计划
1. **环境搭建**：配置Python虚拟环境，安装依赖库。
2. **基础界面**：完成Streamlit主页面开发。
3. **接口联调**：对接哈工大AI平台，实现基础对话。
4. **本地部署**：确保程序可在本地一键运行。

## 五、预期效果
1. **准确性**：校园常规问题回答准确率 ≥ 90%。
2. **响应性**：单次问答响应时间 ≤ 5 秒。
3. **易用性**：无需安装，打开网页即可使用。
