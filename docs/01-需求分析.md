# HIT-CampusAI 需求分析文档（V1.0）

## 一、项目背景
哈尔滨工业大学拥有一校三区的办学格局，校园信息分散在官网、微信公众号、哈工大APP等多个平台。师生在办理事务、获取生活服务时，常面临“信息查找难、流程不清晰、响应不及时”的痛点。

本项目依托哈工大AI智能创新大赛提供的技术资源，旨在打造一款轻量化、高精准的校园AI生活助手，打通校园服务的“最后一公里”。

## 二、核心用户群体
1. **新生**：急需快速了解校园布局、办事流程、选课规则的群体。
2. **在校老生**：追求高效校园生活，需要食堂推荐、活动提醒、图书馆服务的群体。
3. **教职工**：需要快速查询校园公共服务信息的群体。

## 三、核心痛点与解决方案
| 序号 | 用户痛点 | 解决方案 | 功能模块 |
| :--- | :--- | :--- | :--- |
| 1 | 办事流程复杂，多次跑腿询问 | 自然语言智能问答，即时解答 | 校园智能问答 |
| 2 | 食堂窗口众多，不知如何选择 | 基于口味和时段的个性化推荐 | 食堂美食推荐 |
| 3 | 校园活动繁多，容易错过重要信息 | 自动整理并推送关键活动 | 活动智能提醒 |
| 4 | 学业压力大，缺乏便捷的疏导渠道 | 提供科普性心理支持内容 | 轻量心理支持 |

## 四、需求优先级（MoSCoW法则）
为确保单人开发进度可控，对需求进行优先级划分：
- **必须实现 (Must)**：校园智能问答（核心）、Streamlit网页端。
- **应该实现 (Should)**：食堂美食推荐、活动提醒。
- **可以实现 (Could)**：语音交互、多校区个性化配置。
- **暂不实现 (Won't)**：小程序开发、校内系统账号登录。
