# HIT-CampusAI 需求分析文档（V1.1 · 深圳校区版）

## 一、项目背景
哈尔滨工业大学“一校三区”办学格局下，深圳校区作为重要组成部分，校园信息分散在校区官网、公众号、通知群等多个渠道，师生在办理事务、获取生活服务时，常面临“深圳校区信息查找难、流程不清晰、响应不及时”的痛点。

本项目依托哈工大AI智能创新大赛提供的技术资源，聚焦**深圳校区**场景，打造轻量化、高精准的校园AI生活助手，打通深圳校区服务的“最后一公里”。

## 二、核心用户群体
1.  **深圳校区新生**：急需快速了解深圳校区布局、办事流程、选课规则的群体。
2.  **深圳校区在校老生**：追求高效校园生活，需要食堂推荐、活动提醒、图书馆服务的群体。
3.  **深圳校区教职工**：需要快速查询深圳校区公共服务信息的群体。

## 三、核心痛点与解决方案
| 序号 | 用户痛点 | 解决方案 | 功能模块 |
| :--- | :--- | :--- | :--- |
| 1 | 深圳校区办事流程复杂，多次跑腿询问 | 自然语言智能问答，即时解答 | 校园智能问答（深圳校区专属） |
| 2 | 深圳校区食堂窗口众多，不知如何选择 | 基于口味和时段的个性化推荐 | 食堂美食推荐（深圳校区专属） |
| 3 | 深圳校区活动繁多，容易错过重要信息 | 自动整理并推送关键活动 | 活动智能提醒（深圳校区专属） |
| 4 | 学业压力大，缺乏便捷的疏导渠道 | 提供科普性心理支持内容 | 轻量心理支持 |

## 四、需求优先级（MoSCoW法则）
为确保单人开发进度可控，对需求进行优先级划分：
- **必须实现 (Must)**：深圳校区校园智能问答（核心）、Streamlit网页端。
- **应该实现 (Should)**：深圳校区食堂美食推荐、深圳校区活动提醒。
- **可以实现 (Could)**：语音交互、深圳校区个性化配置。
- **暂不实现 (Won't)**：小程序开发、校内系统账号登录、本部/威海校区信息接入。
